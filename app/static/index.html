EVALUATION / REPLAY

怎么评测，而不是怎么演示

项目包含独立的离线回放评测，对同一批固定材料运行三条策略线，避免把演示动画当成效果。

A

单次搜索直出

一次搜索、少量读取后直接总结，作为低成本基线。

B

固定查询链

与 Agent 同预算，但查询、读取和停止规则固定。

C

证据缺口自适应

依据日期、条件、冲突与覆盖缺口决定是否定向补搜。

运行方式

python -m evaluation.run_replay

命令会输出 A/B/C 的覆盖率、引用支持率、重复率、补搜收益与调用消耗，并生成可人工标注的 CSV 模板。固定材料结果与实时 Tavily 结果分开记录。

限制说明

没有密钥时，真实检索效果尚未验证。回放使用合成的固定材料与确定性模型替身，只能检验检索策略和工程闭环，不能外推为线上模型能力。
